# Digital Advertisement Performance Prediction

A machine learning project using Python and Scikit-learn to classify digital advertisement campaign performance as Low, Medium, or High.

## Algorithm
- Random Forest Classifier
- OneHotEncoder for categorical features
- Train/test split
- Classification report
- Confusion matrix

## Features
- Platform
- Advertisement type
- Budget
- Impressions
- Click-through rate
- Engagement rate
- Target audience
- Campaign duration

## Target
- Low
- Medium
- High

## Installation

```bash
pip install -r requirements.txt
```

## Train the model

```bash
python train_model.py
```

## Make a prediction

```bash
python predict.py
```

The included dataset is synthetic and intended for academic and educational use only.
